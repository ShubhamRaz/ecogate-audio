# Limitations and Threats to Scientific Validity

This document outlines the methodological boundaries, addressed historical anomalies, and remaining threats to scientific validity for the **EcoGate-Audio** project.

---

## 1. Resolved Historical Limitations

### 1.1 Dataset Provenance & Archive Reconciliation (Resolved)
- **Historical Discrepancy:** Previous documentation noted a discrepancy between an 8,663-file local audit and an 8,512-file Mendeley archive observation.
- **Root Cause & Resolution:** The 151-file difference was traced to synthetic test fixtures generated by `generate_reference_validation_archive()` when run in an environment without the authentic archive. The genuine Mendeley release (DOI `10.17632/p6m5tmr477.1`) contains **strictly 8,512 WAV files** with SHA-256 checksum `9f9715801b2133f9c635dfcf3fc931fbff79fdf9f4850ec4feadccba609bb51f`.
- **Integrity Enforcement:** All 151 synthetic fixture files have been quarantined to `data/synthetic_fixture/`. The canonical raw directory (`data/raw/`) contains strictly the 8,512 authentic field recordings. Automated integrity checks in `scripts/validate_dataset.py` prevent synthetic samples from entering training, calibration, or evaluation pipelines.

### 1.2 Model Architectures: Fixed-Feature Projections vs. Deep Neural Networks (Resolved)
- **Historical Limitation:** Early prototype versions utilized handcrafted spectral summaries and frozen random linear projections, misleadingly designated as "CNN" and "AST" models.
- **Resolution:** Replaced with genuine, trainable PyTorch deep neural architectures (`src/models/pytorch_models.py`):
  - **StudentCNN:** Lightweight 4-block 2D convolutional neural network operating directly on Log-Mel spectrograms, featuring BatchNorm, GELU activations, max pooling, adaptive average pooling, and dual classification/bird-activity heads (224,965 trainable parameters).
  - **ExpertTransformer:** Patch-based Audio Spectrogram Transformer featuring non-overlapping $8 \times 8$ patch projections, learnable `[CLS]` token, sinusoidal 2D positional encodings, 4-layer multi-head self-attention transformer encoder, and multi-head outputs (~1.48M trainable parameters).
  - Both architectures are trained via gradient backpropagation using AdamW, cosine annealing learning-rate schedules, gradient clipping, early stopping, and validation-based checkpointing.

### 1.3 Quantization: Matrix Storage vs. Integer Runtime Execution (Resolved)
- **Historical Limitation:** Previous INT8 implementations compressed weight arrays in `.npz` archives but dequantized them to `float32` prior to matrix multiplication.
- **Resolution:** Implemented `TorchQuantizedStudentModel` (`src/deployment/edge_engine.py`) using PyTorch dynamic quantization (`torch.ao.quantization.quantize_dynamic`). The linear projection and head layers execute true `torch.qint8` integer matrix operations at runtime on CPU backends, accompanied by temperature recalibration on the held-out calibration split.

### 1.4 Routing Cost Formulation & Ranking Invariance (Resolved)
- **Historical Limitation:** Unsubstantiated claims of "variable per-sample cost optimization" when expert invocation incurred a constant computational cost.
- **Resolution:** Formulated and mathematically proved Theorem 1 (Ranking Invariance Under Constant Invocation Cost): subtracting a constant cost $C_e$ from predicted sample benefits is order-isomorphic under `argsort` and cannot alter sample priority. Cost awareness is rigorously formulated as an optimal threshold floor ($\tau^* \ge \lambda C_e$) determined on the calibration partition subject to strict call-rate and cumulative budget caps.

## 2. Current Methodological Scope & Threats to Validity

### 2.1 Acoustic Diversity and Source Metadata Independence
- **Field Recording Origin:** The 8,512 recordings originate from South African avian bioacoustic surveys deposited in Mendeley Data (DOI: 10.17632/p6m5tmr477.1).
- **Session Clustering:** Recording sessions and 37 duplicate waveform groups (76 files) have been strictly isolated into group-safe splits (Train: 5,108; Calibration: 852; Validation: 1,276; Test: 1,276) ensuring 0 cross-split leakage.
- **Threat:** While duplicate and session groupings are safe, full geographical and microclimate independence across recording locations cannot be mathematically guaranteed due to unstandardized GPS coordinates in the original archive metadata. Generalization to novel geographic biomes remains an empirical question for future cross-dataset studies.

### 2.2 Open-Set Taxonomy
- **Closed vs. Open-Set Distinction:** The closed set consists of 4 target species (*Ploceus cucullatus*, *Quelea quelea*, *Crithagra mozambica*, *Estrilda astrild*).
- **Heterogeneous Noise:** Unfamiliar species are curated in `other_birds` (2,508 clips). Environmental noise (2,000 clips) is evaluated independently to avoid conflating abiotic environmental acoustic events (wind, rain, mechanical noise) with novel biological taxa.
- **Downstream Held-Out Rotations:** Leave-one-species-out cross-validation evaluates downstream open-set rejection. This isolates classification decision boundaries from training exposure.

### 2.3 Hardware & Electrical Power Benchmarking
- **Current Measurement Status:** CPU latency (mean and P95), memory footprint (peak KB), model storage footprint, and floating-point/integer parameter complexity are measured directly on the host execution platform using reproducible benchmarking scripts (`src/benchmarking/energy_benchmarker.py`).
- **Pending Physical Measurements:** True physical electrical energy consumption (Joules) measured via an in-line USB hardware power meter (e.g., Monsoon High Voltage Power Monitor or USB power analyzer) on an embedded Raspberry Pi Zero 2 W is currently documented as `not_measured_proxy_cost_units_only`.
- **Scientific Integrity Commitment:** EcoGate-Audio reports proxy compute cost units and wall-clock latencies directly, and explicitly disclaims theoretical estimates as physical hardware measurements until physical lab bench profiling is conducted.
