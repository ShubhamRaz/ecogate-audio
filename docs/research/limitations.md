# Limitations and Threats to Validity

1. **Archive provenance is unresolved:** the historical audit report lists 8,663 WAV files, while a preliminary archive observation lists 8,512. The 151-file difference matches the default synthetic fixture output. The raw WAV archive is not versioned in this repository, so mixing cannot be confirmed from the repository alone. Re-audit the authoritative archive in a clean raw-data directory before using any reported counts.
2. **Source metadata is incomplete:** filename-derived session identifiers and exact duplicates can be grouped, but unknown sources cannot be guaranteed geographically or temporally disjoint. Describe the current splits as duplicate-safe and grouped by identifiable provenance only.
3. **Model architecture is classical/fixed-feature, not deep neural:** the legacy student class uses handcrafted statistics, frozen random projections and fitted output heads. The expert uses handcrafted spectral summaries and fixed random attention projections; its learned output components do not make it a trained AST. A genuine trainable CNN/AST needs a separate implementation and fresh experiments before those architecture names can be claimed.
4. **Open-set taxonomy:** `other_birds` is a heterogeneous pool and environmental noise is not an unseen species. Leave-one-species-out testing is a downstream split; prior exposure from any external pretrained encoders would need explicit controls if such encoders are introduced.
5. **Routing-cost assumptions:** expert invocation cost is treated as constant. Under a fixed call budget, subtracting the same cost from every predicted benefit does not alter the ranking; only the call threshold changes. Per-sample cost-aware claims require measured or defensible heterogeneous costs. The offline oracle uses test-label loss and is non-deployable.
6. **Quantization:** the current wrapper stores some matrices as INT8 but dequantizes to float32 for inference. No integer-only execution or ONNX Runtime acceleration is implemented.
7. **Hardware energy and edge evidence:** energy in joules has not been measured with an external power meter. Raspberry Pi Zero 2 W deployment has not been physically benchmarked. Exact model MAC/FLOP counts are unavailable until operation-level accounting is added.
8. **Historical result files:** committed metrics were generated before the corrections on the fix branch and must not be cited. They must be regenerated from the verified source archive with the current implementation.
